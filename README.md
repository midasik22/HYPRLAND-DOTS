# Hyprland Configs 🖤

This repository contains my personal **Hyprland** configuration files for a sleek, minimal, and highly customizable Wayland desktop environment.  

---

## 🚀 Features

- Custom layouts and workspaces  
- Floating & tiling window rules  
- Subtle animations and blur effects  
- Minimalist status bar with widgets  
- Keybindings optimized for productivity
